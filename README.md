# Stellar Burgers · API-тесты

Учебный дипломный проект Яндекс Практикума: проверки регистрации, авторизации и создания заказов через API Stellar Burgers. Проект прошёл ревью и принят.

**Python · Requests · pytest · Allure**

[Портфолио автора](https://github.com/DuVla) · [Юнит-тесты](https://github.com/DuVla/Diplom_QA_Yandex) · [UI-тесты](https://github.com/DuVla/Diplom_QA_Yandex_UI)

## Покрытые сценарии

| Группа | Проверки |
|---|---|
| Регистрация | Уникальный пользователь; повторная регистрация; отсутствие обязательного поля |
| Вход | Существующий пользователь; неверные учётные данные |
| Заказ | С авторизацией; без авторизации; с ингредиентами; без ингредиентов; с некорректным хешем |

Всего **10 тестов**. Проверяются статус и содержимое ответа. Для ошибки `500` с некорректным хешем учитывается фактический HTML-формат ответа сервера.

## Подход

- Отдельный тестовый класс для каждого эндпоинта.
- Уникальные пользователи создаются через API в фикстуре и удаляются при её завершении.
- Проверки результата находятся в тестах; подготовка и очистка данных — в фикстуре.
- Повторяющиеся HTTP-запросы вынесены в `api_requests.py`.
- В запросах настроены таймауты, шаги видны в Allure.

## Установка и запуск

Нужны Python 3 и доступ к учебному API:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest tests -v
```

На Windows для активации: `.venv\Scripts\activate`.

Создание нового отчёта:

```bash
python -m pytest tests --alluredir=allure-results --clean-alluredir
allure serve allure-results
```

## Структура

```text
tests/
  conftest.py          # подготовка и удаление пользователя
  register_test.py     # регистрация
  login_test.py        # авторизация
  order_test.py        # создание заказа
api_requests.py        # HTTP-запросы и шаги Allure
user_generator.py      # генерация тестового пользователя
ingredients.py         # получение идентификаторов ингредиентов
url.py                 # адрес API и таймаут
reports/               # сохранённый отчёт и инструкция
```

Тесты работают с внешним учебным сервисом; его доступность влияет на время и результат запуска. Репозиторий демонстрирует учебный опыт автоматизации API.
